Edge cases reviewed
-------------------
1. Dodge counter precedence: vanilla martial-arts counter remains first; Survivor Riposte is fallback-only.
2. Unsafe automatic target selection: dead, hallucination, friendly and neutral sources are rejected; adjacency and stamina are required.
3. Recursive counter chains: thread-local riposte guard remains in place.
4. Zero-effect critical farming: reactive critical rewards require dealt_damage > 0 and a real target.
5. Kill farming: zero-XP revived targets are rejected; friendly/passive/neutral kills are rejected; attacking/fleeing combat targets with XP remain valid.
6. Self-damage amplification: 0.11.1 source != this outgoing/execute guard remains required by audit.
7. Momentum stale/corrupt state: stack and timer reads are bounded; missing owner perk clears state.
8. Respec carryover: full respec explicitly zeros Momentum stack/timer state before recalculation.
9. World-load transient state: existing 0.11.0 world-load reset remains intact.
10. Craft failure cancellation: saved failures still schedule the next failure point before returning.
11. Craft UI parity: displayed recipe success estimate still includes the same success-roll bonus used by the failure-point roll.
12. Lockpick lost-item path: perfect-lockpick test is null-safe; normal/perfect timing floors remain 30 s / 5 s.
13. Alarm Bypass scope: user-facing text now matches the actual alarmed-door hook.
14. Reapply/idempotence: an already-generated 0.11.2 source is node-count/state-schema/required-perk audited before being accepted.
15. Perk preservation: 0.11.2 changes mechanics/text only; it does not intentionally add or remove nodes and its transform requires pre/post node-count equality.
