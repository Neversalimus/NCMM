Mechanical boundaries
- Automatic riposte is recursion-guarded and suppresses a second automatic vanilla dodge-counter selection only when the NCMM riposte actually fired.
- Execute is a bounded damage-window mechanic (target <= configured HP threshold), not unconditional death.
- Momentum state is module-owned and driven by a generic player-kill event; Host/CDDA contain no concrete perk IDs.
- Momentum is cleared on world-load event, expires by turn TTL, and recalculates runtime modifiers only when state changes.
- Craft failure cancellation schedules the next failure point before returning, preventing the same failure point from immediately re-firing.
- Lockpick time keeps the vanilla five-second minimum.
