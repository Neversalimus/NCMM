5. NVIDIA - NVTX core headers (optional diagnostic annotations)
-------------------------------------------------------------
Source: https://github.com/NVIDIA/NVTX
License: Apache License 2.0 with LLVM Exceptions
Unmodified core headers from the signed NVIDIA Nsight Graphics
2026.3.1.26224 Windows distribution; individual source hashes are recorded in
experiments/graphics_bridge/third_party/nvtx3/manifest.json.
This is a header-only library. NCMM does not link or require a separate NVTX or
NGFX runtime DLL. Calls are disabled during ordinary performance measurements.
The complete license is supplied as NVTX-LICENSE.txt in the preview package.

CC0 held item meshes and material palettes
----------------------------------------
The First Person TEST module compiles 30 distinct author models from the
following CC0 packs. Their pinned author files, exact versions, SHA256 values,
offline calibration and conversion results are recorded in
experiments/FirstPersonView/assets/held_items/selection.json and generated/manifest.json.

First Person View world furniture
--------------------------------
Kenney Furniture Kit: https://kenney.nl/assets/furniture-kit
License: CC0 1.0 Universal. The original author's License.txt and 43 selected
static GLB meshes are retained under experiments/FirstPersonView/assets/world_props.
Original archive SHA256:

Authored node transforms are baked offline; coordinates are converted from

with mild runtime weathering. No runtime model importer or network access.

Weapon gas/flash sprites are original procedural art; reference links in
weapon-effects.references.json do not redistribute source footage or audio.

Only the selected visual node is imported; exporter collision geometry, lights
