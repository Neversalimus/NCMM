NCMM — EQUIPMENT BODY MAP v2 / PR #187
TEST PACKAGE — CDDA experimental 2026-09-23-0546 ONLY
=====================================================

ВНИМАНИЕ: это предварительная сборка для проверки новой куклы
в нижней правой части обычного инвентаря. Не является стабильным релизом.
Используйте копию папки CDDA и резервную копию сохранений.

СОВМЕСТИМОСТЬ
-------------
Поддерживается ТОЛЬКО CDDA experimental 2026-09-23-0546
исходный commit e262adb299a7613b4aedc5f12c08fe0413c56a84.
Скрипт проверяет VERSION.txt, SHA-256 оригинального exe, установленный
NCMM bootstrap и наличие EquipmentBodyMap. Для других сборок установка
отменяется БЕЗ изменения файлов. Это намеренно.

УСТАНОВКА
---------
1. Распакуйте ZIP за пределами папки CDDA.
2. Если NCMM ещё не установлен в этой КОНКРЕТНОЙ копии CDDA:
   запустите NCMM_Setup.exe, выберите нужные модули,
   в том числе Equipment Body Map, и Install / Repair.
3. Запустите Install_EBM_TEST.cmd. Выберите папку этой CDDA.
4. После сообщения INSTALLED найдите в папке игры
   RUN_EBM_PR187_TEST.cmd и запускайте тест ТОЛЬКО через него.
   Этот запуск использует --ncmm-offline, чтобы обычный online feed
   не заменил экспериментальный Host стабильным автоматически.

ПРОВЕРКА
--------
Откройте обычный инвентарь (не Advanced Inventory).
Внизу справа должна появиться графическая кукла. Проверьте:
- наведение и клик на голову, туловище, руки, кисти, ноги, ступни;
- скованность на разных частях тела и список надетых предметов;
- подсветку покрытия выбранной брони;
- узкое окно и небольшую высоту окна;
- отсутствие скованности у отсутствующих частей тела при мутациях;
- работу прежней навигации инвентаря.

ВОССТАНОВЛЕНИЕ
--------------
Закройте игру. Запустите RESTORE_EBM_PR187_TEST.cmd в папке CDDA.
Оригинальный Host и host.binding.json вернутся из резервной копии
ncmm/ebm-pr187-backup. Инсталлятор НЕ трогает сохранения.
Если резервная копия повреждена или файлы были изменены после
установки, восстановление остановится, не удаляя резервную копию.
