V8.7.5

1. World-options live language refresh
- options.cpp now dispatches ncmm::on_language_changed() immediately after set_language_from_options().
- Advanced World Settings already exports ncmm_on_locale_changed_v1; the callback re-registers vanilla-exposed and synthetic world-setting names/tooltips using the new locale.
- Patched-source integrity requires exactly one options-language dispatch hook.

2. Real overview detail frame
- ui_card_choose now reserves a right-hand detail pane when NCMM_UI_THEME_SECTIONED_DETAIL is active.
- The selected card title/subtitle/badge/body render in that pane.
- Card bodies are reduced to one visible line in the grid while the detail pane keeps the full text.
- Core branches expose HOW TO GAIN XP and EFFICIENCY; mod branches explicitly say there is no separate branch XP.

3. Prime layout
- Prime roots/capstones stay in compact 0/1/2 lanes.
- Host layout does not parent-recenter NCMM_UI_BORDER_PRIME nodes, preventing sibling Prime nodes from collapsing onto each other.
- Horizontal viewport remains active for narrow layouts.

4. Player-facing copy cleanup
- Removed remaining development-style phrases such as audited/mod-native/source-scoped from visible branch descriptions.
