NCMM / Survivor Progression v8.7.6.2 — Smoke Anchor Hotfix

Fixed
-----
- Fixes false `NCMM API 1.8 smoke initializer anchor missing` during source transform.
- Root cause: API 1.7 intentionally inserted the smoke initializer with TrimEnd(), while the redundant API 1.8 `.Contains()` precheck used the raw Windows here-string including its trailing CRLF.
- API 1.8 now relies on `Replace-TextBlock`, which already normalizes LF/CRLF, trims block edges, and enforces an exact single match.

- v8.7.6 Clarity Pass behavior.
- v8.7.6.1 CMD BOM fix and reliable exit-code capture.
- dormant Recipe Finalization Profiler host support.

No gameplay balance or recipe semantics changed.
