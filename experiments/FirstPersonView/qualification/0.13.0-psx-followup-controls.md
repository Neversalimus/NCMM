# Additional native controls and GPU contracts

These short diagnostic comparisons are not release qualification. They use 12 scene/viewport/renderer records, 12 steps and 48 cold plus 48 warm turns per record. A 12-step p99 is not reliable rare-tail evidence.

R8 changes only the Host, with identical module bytes and 30 other payload files, in pre/new/post order. R11 compares original/four-stream hashing on the same new Host; the module source difference is exactly scene_hash.hpp. All negative samples remain in the archive.

The large geometry-wall spikes in the middle R8 run did not recur in a later identical-binary repeat. Original hashing also exhibited large spikes. These observations do not isolate hashing or neutral-texture initialization as the cause. Ordinary rotation still regressed, so source551 was not accepted for final performance qualification.

The existing detailed CPU profiler did not reproduce the large geometry-wall delay. Four separate owned checkpoint stacks include CPU hashing and a Direct3D 12 synchronization wait during native submission; their timing was deliberately perturbed and is excluded from performance comparisons. Raw dumps stay local.

Runtime candidate [3e9c8b0](https://github.com/Neversalimus/NCMM/commit/3e9c8b065f23a73ae660dd028aab5dcc851df451) compares complete prepared cell records and retains identical GPU cell data. It preserves all native inputs and GPU passes. Actual RTX4090/D3D12 MSVC and Clang ASan/UBSan checks pass, including four queued lighting snapshots, 16 queued poses and 32 queued teardowns. This proves correctness and skipped redundant transfers; native latency is still pending.

The standalone tests use SDK SDL3.4.0; both pinned native Hosts use SDL3.4.10. CPU recording timers are not GPU execution timestamps. No final Full or merge acceptance is implied.

Native dependency versions follow the [pinned upstream manifest](https://github.com/CleverRaven/Cataclysm-DDA/blob/3f7fb352bf492ba521bd9408a0c9f6ce239e8d83/msvc-full-features/vcpkg.json) and [SDL port](https://github.com/microsoft/vcpkg/blob/f6672d8e480ccdecddfad3fd1b838ba369ffe6cd/ports/sdl3/vcpkg.json). The [SDL upload contract](https://wiki.libsdl.org/SDL3/SDL_UploadToGPUTexture) permits subsequent commands to consume a queued upload. Its [3.4.10 D3D12 implementation](https://github.com/libsdl-org/SDL/blob/release-3.4.10/src/gpu/d3d12/SDL_gpu_d3d12.c) can allocate temporary alignment storage when unrestricted copy pitches are unavailable. That driver capability was not established here; repeated neutral uploads were redundant regardless, and their removal is not claimed to explain every outlier.
