# Church geometry, primary attacks and grass candidate

This extends the existing 0.13.1 controls candidate in PR #223. It remains
`0.13.1-dev`; rebuilt packages require fresh Native qualification. Existing
results for older Host/DLL bytes are checkpoints, not certification of this
change. The public feed and release status are unchanged.

Captured SDL primary clicks belong to FPS even when the hidden virtual mouse
coordinates have moved outside the viewport. Owned hostile reach requests
enter the existing Native fire checks and Native reach attack without opening
the coordinate selector. They revalidate world/entity lifetime, camera, origin,
visibility and the weapon's current range. Native `can_reach_attack` only
checks vertical reach; the direct path separately applies the target UI's
rounded `rl_dist_exact` horizontal limit and same-level rule. Native cost,
obstruction, fatigue warnings and hit rules remain authoritative. RMB retains
ordinary Native targeting. Native cursor refresh and ImGui cannot show the
cursor while FPS owns relative capture; releasing capture restores its policy.

Shape matching now treats `door` as an identifier component, so `indoor` no
longer turns `f_indoor_plant` into a door. The actual Native rural church has
one stair pair offset by a single cardinal tile. Pairing accepts that unique
same-overmap connection, rejects ambiguous/diagonal candidates, and derives
the flight from the lower approach and upper exit. The rendered landing and
floor aperture agree. A wall beneath an offset upper exit retains its lower
support and sides while clearing the upper flight. Only visualization changes;
Native map terrain, movement and visibility rules remain unchanged.

Visible, unoccupied Native grass terrain gets deterministic blade geometry,
root-anchored wind and nested 5/12/22 m levels of detail. Different Native grass
types retain height/colour variation. No downloaded assets or new shader/ABI
are needed. GPU grass is cached and uses existing skeletal transforms; the CPU
renderer animates over its cached static world. Pavement, bare soil, indoor
plants, vehicles and furniture do not acquire grass.

The strict Native input matrix now requires 144 cases across both keyboard
modes and CPU/GPU. Besides successful adjacent and reach attacks, it requires
captured clicks outside the virtual viewport, axial and diagonal out-of-range
refusals with zero move cost, cursor restoration, an actual offset stair
transition, and Native grass presentation with unchanged gameplay state.
Successful reach fixtures reset stamina between matrices and reject a weapon
that would require an interactive slow-attack confirmation; they do not
disable the production warning. Detailed Native cost/modal/attack diagnostics
are retained for failures. Synthetic verifier tests are not Native evidence.
