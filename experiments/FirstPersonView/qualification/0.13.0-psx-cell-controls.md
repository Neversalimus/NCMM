# Cell reuse and normal native execution controls

These ordered diagnostic runs are not final installer or performance acceptance. Each short run contains all 12 scene/viewport/renderer records, 12 steps and 48 cold plus 48 warm turns. All samples, including unfavorable results, are preserved. A 12-step p99 is not reliable rare-tail evidence.

R13 uses new/old/new Hosts with identical source7fd PSX module bytes and 30 other payload files. R15 uses the current source3e9 Host and PSX/old arms without a crash debugger. R16 retains the same current Host and PSX asset, with original hashing; its module source difference is only scene_hash.hpp. R15/R16 show that omitting the debugger and restoring original hashing do not remove the native rotation delay. No runtime or quality change was made for these controls.
