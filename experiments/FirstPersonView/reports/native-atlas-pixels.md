# Exact Native atlas pixels (candidate)

The completed private CPU observer located street cold-frame raw67 at 11.2752 ms geometry, including 11.038 ms scene collection and one 10.1863 ms synchronous sprite readback. Cold24/33 also each contained one 9.323/10.504 ms readback. These are CPU wall timings from the explicitly mixed diagnostic process, not GPU execution or accepted production results.

The existing Native normal-atlas upload now retains exact source pixels in independently compressed 32-row bands. An SDL texture cleanup property owns the bytes through texture/renderer destruction. The first sprite request copies the required pixels without a renderer submission/readback. Unsupported colour space, colour keys, allocation failure, missing data or a full budget use the original GPU path. Resolution, alpha, colours, tile selection and Native drawing stay intact.

The additional compressed source budget is **64 MiB**. The original resolved sprite/composite budget remains **64 MiB**, so the two payloads can total **128 MiB**. This is an explicit memory tradeoff. Compression adds tileset-load CPU work; new Native fields report retained bytes, cumulative encoding milliseconds and successful CPU copies. Actual final Host loading time and resident memory remain to be measured.

All 42 registered local tests passed using the unchanged shipping SDL library. The new actual RTX4090/D3D12 test passed 162 checks: exact GPU RGBA equality including zero/partial alpha, padded pitch, band crossings, source release, invalid bounds, refusal without a partial memory reservation, texture destruction and 16 renderer teardowns. All 19 source-transform tests passed, including atomic rejection of changed/duplicate upload anchors. The new adapter also matched the actual 1040 and 1807 upstream sources and rejected reapplication. The final two transform tests were added after the full42 run. The exact compressed-pixel implementation and GPU-test bytes stayed unchanged. Later Host-only diagnostic glue reuses the existing CameraSnapshotVerify fixture to compare every CPU crop with the original GPU path, requiring at least one check and zero mismatches. Those Host glue edits have not been compiled locally and require the fresh Native builds. Ordinary timing runs do not enable the extra comparisons.

This uses Native's existing required zlib dependency. No module/Host ABI change or shipping dependency is introduced. The earlier clean b6e/4ea ten-run remains rejected (53 repeated metric regressions). Fresh Native builds, correctness, ordinary complete-frame comparisons, prior-tail review and final unchanged hardware/soak qualification are still required. **No production performance acceptance or merge approval.**

Compact hashes and exact scope are in `native-atlas-pixels.json`; large original raw data remain local with SHA-256 bindings.
