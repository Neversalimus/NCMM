Survivor Progression 0.11.3 — Combinatorial Edge Audit

Invariants
- Existing perk count is preserved by transform; no node removal is allowed.

Edge cases covered
1. Riposte + crit/kill move rewards: refund basis is captured before attack and no longer inferred from net moves.
2. Mounted combat: automatic NCMM riposte is suppressed to avoid mech/mount attack-cost mismatch.
3. Vanilla counter selection vs execution: failed vanilla counter attempts no longer falsely consume NCMM fallback.
4. Friendly/neutral/hallucination targets: no reactive crit/execute/Momentum damage amplification.
5. Hostile fleeing monsters: remain valid combat targets/rewards.
6. Hostile NPC death: direct avatar kills receive generic kill recovery/Momentum; fake/hallucination/non-hostile NPCs do not.
7. INT64-corrupted Momentum: values saturate before increment and self-heal to currently owned caps.
8. Momentum at cap: timer refresh does not force a redundant modifier recalculation.
9. Respec/perk loss: transient Momentum is cleared by prior 0.11.2 guards.
10. Craft failure save at zero roll: next failure point is forced strictly beyond current progress.
11. Craft UI: catastrophic failure display includes the runtime failure-save probability.
12. Lockpick null/floor behavior: inherited 0.11.2 protections remain unchanged.
